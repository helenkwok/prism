# PRISM public data

Aggregate findings of the PRISM review, written only by `src/publish/export.ts`.

- `v1/release.json`: the findings release (counts of launches under disclosure control, no launch named).
- `v1/manifest.json`: file digests, the disclosure audit, the process figures and their addendum, the lint and the identifier scan.
- `ledger.json`: every published count with the release that first published it.
